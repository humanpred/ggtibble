# Use the `%+%` operator from `ggplot2` for `ggtibble` and `gglist` objects

Use the `%+%` operator from `ggplot2` for `ggtibble` and `gglist`
objects

## Usage

``` r
e1 %+% e2
```

## Arguments

- e1:

  Either a `ggtibble` or `gglist` object or an object that can use the
  default `ggplot2::%+%` function

- e2:

  A plot component (see ?ggplot2::`%+%`)
